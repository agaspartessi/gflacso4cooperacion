# Campus Cooperación — Moodle 5.3

Rama `moodle-5.3`, versión `2.0.0-beta2` (`2026101901`). Requiere Moodle y Boost 5.3.

Adaptación de `main` de Cooperación con las correcciones técnicas de Uruguay,
conservando paleta verde/violeta, tipografías, recursos, footer y estilos de cursos.
El login conserva el mapa y la distribución de Cooperación de Moodle 5.1.

Ver [cambios e instalación](docs/MOODLE_5_MIGRATION.md). Pendiente de validación visual y funcional en testing.
